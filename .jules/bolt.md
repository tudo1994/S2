## 2024-05-18 - `lodash.merge` vs object spread for style combination
**Learning:** In `@antv/s2-core` cells, `lodash.merge` is used to combine default styles (e.g., `backgroundColor`) with conditional styles. Because `lodash.merge` deep clones by default, it is significantly slower than native object spread (`...`) for flat objects. The conditional styles typically omit missing properties (e.g., returning `{ intelligentReverseTextColor: false }` instead of `{ backgroundColor: undefined, intelligentReverseTextColor: false }`), which makes object spread perfectly equivalent to `lodash.merge` for these flat objects (`{ ...fallback, ...conditionFill }`).
**Action:** Replace `lodash.merge` with object spread for combining default background styles and condition fills in `BaseCell` derived classes (`DataCell`, `RowCell`, `HeaderCell`).

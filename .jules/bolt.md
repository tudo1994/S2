## 2024-06-04 - S2 React Event Handlers Optimization
**Learning:** `packages/s2-react/src/hooks/useEvents.ts` is registering over 90 events directly on `SpreadSheet` with `s2?.on` and using `React.useLayoutEffect` to manage the event listeners. The problem is that it has `handler` in the dependency array. Since consumers usually pass inline functions to `onRowCellClick`, `onDataCellClick`, etc., the `handler` reference changes on almost every re-render. This causes the event listeners to be unbound and rebound constantly, triggering layout effects unnecessarily. This is a common performance pitfall in React components that heavily integrate with vanilla JS event emitters.
**Action:** Used `useLatest(handler)` from `ahooks` to hold the latest handler function in a ref, removing `handler` from the `useLayoutEffect` dependency array. This prevents the constant unbinding and rebinding of event listeners when the handler reference changes, significantly improving rendering performance.

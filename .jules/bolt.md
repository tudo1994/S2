## 2024-06-25 - Avoid lodash.merge in rendering loops
**Learning:** In `@antv/s2-core` and related packages, the rendering engine frequently calls methods like `getBackgroundColor` on cells thousands of times per render. Using `lodash.merge` in these hot paths is extremely slow compared to native object spreading, especially for flat configuration objects. Furthermore, `lodash.merge` safely ignores `undefined` values while `...` does not, so you must use nullish coalescing (`??`) correctly.
**Action:** Replace `lodash.merge` with object spreading and nullish coalescing `??` for flat configurations in rendering loops. When doing so, spread the condition object first, and then explicitly assign fallbacks with optional chaining (`conditionFill?.key ?? fallback`) to prevent `undefined` properties from being incorrectly preserved by the spread operator.

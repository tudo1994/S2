## 2026-10-04 - [Avoid deep merging large objects for background fill]
**Learning:** The `lodash.merge` function was heavily used in cell `getBackgroundColor` getters. Given these cells instantiate their background every time there are interaction changes or data renders, using `merge` adds massive overhead due to the deep merging loops it runs behind the scenes for large scale pivot tables. We observed native spread coupled with nullish coalescing achieves the same fallback merging but is massively faster since we know there's only 1-2 depths of properties to merge here.
**Action:** Replaced `lodash.merge` with native spread operator and nullish coalescing to combine default styles and conditionally overridden background styles in `row-cell.ts`, `header-cell.ts` and `data-cell.ts`.

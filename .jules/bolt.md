## 2024-05-24 - Avoid lodash.merge for style objects
**Learning:** In `@antv/s2-core` and related packages, using `lodash.merge` to combine flat configuration objects like cell styles (`backgroundColor`, etc.) introduces unnecessary overhead. This is particularly impactful when getting background colors in cell rendering, as these methods are called frequently.
**Action:** Replace `lodash.merge` with object spread syntax (`...`) and nullish coalescing (`??`) for flat objects. Ensure the conditionally merged object is spread first so that its properties are properly overridden by defaults if they are `undefined`. For example: `const conditionFill = this.getBackgroundConditionFill(); return { ...conditionFill, backgroundColor: conditionFill?.backgroundColor ?? backgroundColor };`

## 2024-06-25 - Using Spread over lodash.merge for style composition
**Learning:** In the AntV S2 table grid, cell backgrounds (and other styles) are rendered heavily and evaluated repetitively. Using `lodash.merge` to combine default configurations with condition fills introduces deep cloning overhead that can impact rendering performance. When merging flat cell style configurations, native object spreads along with nullish coalescing operators (`??`) provide the same behavior (allowing fallback to defaults where conditionals don't exist) without the overhead. When converting `merge` to spread, beware that `merge` ignores `undefined`, but spread natively overwrites with `undefined`, so ensure fallback logic coalesces properly.
**Action:** Always prefer native ES6 syntax like object spread (`...`) and `??` over deep manipulation utilities like `lodash.merge` for flat, non-nested objects, especially in frequently executed path-rendering code. Assign function results to local variables before spreading to avoid redundant function calls.

## 2024-05-24 - Cell Object Spreading Micro-Optimization
**Learning:** `lodash.merge` is computationally expensive due to its safety checks, deep-clone capacity and type checks. When dealing with hot-path visual logic like `getBackgroundColor` inside cell instances, iterating over potentially millions of cells per grid lifecycle degrades rendering performance. Replacing it with standard object destructuring and `??` conditional fallbacks achieves the same object-assembly goal while removing deep-clone overhead.
**Action:** Replace `lodash.merge` with `{ ...default, ...spread }` pattern when applying lightweight style getters. Since native spread clobbers values with undefined while `lodash.merge` ignores them, utilize conditional `??` assignments like `color: customFill ?? defaultFill` to explicitly defend against overwriting the default object values with undefined.

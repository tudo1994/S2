## 2024-05-18 - Avoid lodash.merge in hot paths
**Learning:** `lodash.merge` is expensive for deep cloning and causes significant overhead when called repeatedly in hot paths like cell style calculations (`getBackgroundColor`). When arrays are involved, `lodash.merge` deeply clones them, whereas direct assignment from `lodash.groupBy` handles defaults efficiently. Also, object spread with nullish coalescing safely handles fallback behaviors compared to `lodash.merge`, given that the source object doesn't contain unintended `undefined` values.
**Action:** Prefer native object spread (`...`) with nullish coalescing (`??`) for flat config merging and direct property assignment for array defaults in performance-critical code sections to reduce execution time and garbage collection overhead.

## 2024-05-19 - Replacing lodash.merge with object spread
**Learning:** `lodash.merge` ignores `undefined` values from the source object, while object spread (`...`) overwrites existing properties with `undefined`. In `@antv/s2-core`, methods like `getBackgroundConditionFill()` that provide conditional styles may return undefined properties if not explicitly mapped. When combining these with base styles, we must safely extract and coalesce properties (using `??`) instead of a blind object spread to prevent accidentally reverting defaults to `undefined`.
**Action:** When replacing `lodash.merge` with object spread for style combination, construct the returned object carefully, falling back to base styles. E.g., `backgroundColor: conditionFill?.backgroundColor ?? backgroundColor`.

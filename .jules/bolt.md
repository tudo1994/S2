## 2024-06-20 - [Performance] Removing lodash.merge for style objects
**Learning:** `lodash.merge` has significant overhead for deeply cloning and merging simple flat configuration objects, particularly in hot paths like cell rendering in grids (e.g. `getBackgroundColor`). Object spreading and nullish coalescing achieves the same outcome much faster. When replacing `lodash.merge` with object spreading, be careful not to unnecessarily declare fallback object properties *before* the spread, as this violates strict type constraints and generates TypeScript duplicate identifier errors. Also ensure that you correctly remove unused `lodash` imports from the files modified.
**Action:** Always prefer native object spreading (`...`) and nullish coalescing (`??`) for flat config merging over `lodash.merge` to minimize rendering bottlenecks. Spread the source object first and then coalesce specific fields as fallbacks.

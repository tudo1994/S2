## 2024-05-24 - Avoid lodash.merge in hot rendering paths\n**Learning:** The `lodash.merge` function is notoriously slow due to its recursive nature, prototype checking, and deep cloning logic. Using it inside hot execution paths like cell rendering methods (e.g., `getBackgroundColor` across `DataCell`, `HeaderCell`, and `RowCell`) creates a significant performance bottleneck during table scrolling and interaction.\n**Action:** Always favor native object spread syntax (`...`) combined with the nullish coalescing operator (`??`) when composing or overriding flat configuration objects (like style or bounds definitions) inside high-frequency rendering methods to dramatically reduce CPU overhead.

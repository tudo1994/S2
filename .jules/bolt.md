## 2024-05-24 - Avoid deep merge tools for flat object combining
**Learning:** In high-frequency rendering paths (like canvas cell drawing), using full-featured functions like `lodash.merge` to combine small, flat styling objects adds unnecessary CPU overhead due to deep merging logic, type checking, and circular reference safety mechanisms.
**Action:** For combining simple configurations (e.g., cell styles, background configurations), use native object spread (`...`) with explicit nullish coalescing (`??`) fallbacks when replacing `lodash.merge`, while making sure to spread the conditionally merged object *first* to avoid overwriting coalesced fallbacks with `undefined` values.

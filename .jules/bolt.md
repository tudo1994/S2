## 2024-05-19 - Replace lodash.merge with Object spread for performance in getBackgroundColor
**Learning:** `lodash.merge` is significantly slower than native object spread (`...`). In tight loops like rendering thousands of cells (DataCell, RowCell, HeaderCell), this creates a performance bottleneck. The `getBackgroundColor` and `getBackgroundConditionFill` methods return simple flat objects, so we can replace `lodash.merge` with object spread and nullish coalescing `??`. Note that `lodash.merge` ignores `undefined` properties, while object spread sets them. So we should construct a fallback object using `??` carefully.
**Action:** Replace `lodash.merge({ backgroundColor, backgroundColorOpacity }, this.getBackgroundConditionFill())` with `{ backgroundColor: conditionFill?.backgroundColor ?? backgroundColor, backgroundColorOpacity: conditionFill?.backgroundColorOpacity ?? backgroundColorOpacity, intelligentReverseTextColor: conditionFill?.intelligentReverseTextColor ?? false }` in `HeaderCell`, `DataCell` and `RowCell`.

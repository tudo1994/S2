## 2024-10-02 - Cell Styling Deep Clone Bottleneck
**Learning:** `lodash.merge` is dangerously slow when used inside hot paths like cell background color getters (`getBackgroundColor` in `data-cell`, `header-cell`, `row-cell`) which evaluate thousands of times during scroll or render. Since `getBackgroundConditionFill()` returns simple flat objects, we don't need deep merging or prototype traversal.
**Action:** Always replace `lodash.merge` with native object spreading (`...`) combined with nullish coalescing (`??`) for safely merging fallback configs inside hot path renders, yielding a massive performance boost at virtually no memory cost. Make sure to defensively optional-chain properties (e.g. `obj?.key ?? fallback`) as standard behavior in S2 is to omit keys instead of returning `undefined`.

## 2024-06-25 - Lodash Merge Overhead in Render Loops
**Learning:** `lodash.merge` is dangerously slow when used inside hot code paths like cell render methods (`DataCell`, `HeaderCell`, `RowCell`) where it is called thousands of times per scroll interaction. Since conditional cell styles in S2 are flat configuration objects, the heavy deep clone operations from `merge` cause significant overhead. Furthermore, replacing it directly with object spread `{...a, ...b}` fails because object spread overwrites existing values if the property exists but is undefined on the source object, whereas `lodash.merge` ignores undefined source values.
**Action:** Replace `lodash.merge` in hot paths with explicit instantiation combined with the nullish coalescing operator (`??`). This achieves the same "ignore undefined source values" behavior safely and avoids the cloning cost on flat configuration objects.

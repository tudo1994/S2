## 2024-05-24 - Object Spread for Merging Objects
**Learning:** In `@antv/s2-core` and related packages, avoid using `lodash.merge` or `cloneDeep` for combining or duplicating flat configuration objects (like cell styles). Prefer native object spread (`...`) for significantly better rendering performance. `lodash.merge` ignores `undefined` source values, while object spread overwrites existing properties with `undefined`. Ensure the source object does not return unintended `undefined` values. When replacing `lodash.merge` with object spread (`...`) and nullish coalescing (`??`), always spread the conditionally merged object *first* (e.g., `{ ...source, key: source?.key ?? fallback }`). Spreading it at the end will cause any `undefined` values in the source to overwrite the safely coalesced fallbacks.
**Action:** Replace `merge` with object spread where appropriate, handling potentially undefined properties properly using nullish coalescing.

## 2024-06-25 - Replace `lodash.merge` with object spreading and nullish coalescing in hot paths
**Learning:** In a high-frequency "hot path" like a data grid library's cell styling methods (e.g., `getBackgroundColor` executed per-cell and per-render), the overhead of deep-merge utilities like `lodash.merge` can become a measurable performance bottleneck. However, a naive object spread replacement (`{ ...fallback, ...source }`) can cause bugs if the source object explicitly returns `undefined` for properties, because object spread overwrites fallbacks with `undefined`, whereas `lodash.merge` ignores `undefined` values.
**Action:** When replacing `lodash.merge` in such paths, spread the source object *first*, and then conditionally apply fallbacks using nullish coalescing (`??`) to defensively handle potentially `undefined` values from the source, guaranteeing exact behavioral parity while avoiding deep-merge overhead (e.g., `{ ...source, key: source?.key ?? fallback.key }`).

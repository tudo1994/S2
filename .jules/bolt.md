## 2024-05-19 - Removed lodash.merge from critical cell render paths
**Learning:** In `@antv/s2-core`, using `lodash.merge` for combining or duplicating flat configuration objects (like cell styles and conditions) introduces unnecessary overhead during rendering. Flat objects, such as `backgroundColor` setups, should ideally be constructed using native object spread syntax (`...`) for better rendering performance. `lodash.merge` should be avoided for simple object assignment and optional properties matching on these hot paths.
**Action:** Replaced `lodash.merge` instances in `data-cell.ts`, `row-cell.ts`, and `header-cell.ts` with native object spread and nullish coalescing to merge styles safely. Always check for `undefined` properties explicitly when relying on optional chaining fallback configurations instead of deep `lodash.merge` implementations on high frequency re-renders.

## 2024-05-24 - Maximum call stack size exceeded in Decimal aggregations
**Learning:** Using the spread operator (`...array`) as arguments to functions like `Decimal.sum(...array)` or `Decimal.max(...array)` causes "Maximum call stack size exceeded" errors for large datasets (e.g., > 100k items) because JS engines limit the number of arguments that can be passed to a function. In `s2-core`, the `number-calculate.ts` aggregations used spread over large mapped datasets, causing production crashes for huge data tables, and degraded performance due to massive array allocations.
**Action:** When calculating sums or max/mins for datasets, always use iterative approaches (like loops or `.reduce()`) instead of the spread operator, especially for libraries like `decimal.js`. This is safer for large lists and avoids massive intermediate array allocations.
